# Security Policy

## Supported versions

No version of `ojs-ctn` is currently supported for production use. This is an
OJS Labs experiment with no security-update, hosted-service, or compatibility
service-level commitment. Security fixes may be provided on a best-effort
basis.

The ML-DSA implementation is a placeholder and must not be relied upon as
production cryptography.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
**security@openjobspec.org** with a description, reproduction steps, affected
revision, and potential impact. Please allow the maintainers time to
investigate before public disclosure.
